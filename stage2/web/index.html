The brain is up.

This server wraps the poio skill (pantry + recipes) behind a JSON API. The encoder companion app lands here next milestone; for now, the endpoints it will drive:

  • GET /api/health
  • GET /api/pantry · ?filter=attention
  • GET /api/recipes
  • GET /api/recipes/{id}
  • GET /api/recipes/{id}/consumed — the "used tonight?" prediction
  • GET /api/today
  • POST /api/pantry/apply — write the pantry update back
  • POST /api/suggest
